# ALPHA TERMINAL 리서치 제품 진단과 리모델링

진단 기준: 2026-11-14. 목적은 미국 상장 주식의 산업·기업 변화와 위험을 수주~수개월 관점으로 검토하는 제품이다. 실제 수익을 보장하거나 모든 기업의 리서치를 완료한 제품으로 표현하지 않는다.

## 새 제품 흐름

1. **오늘의 리서치**: SPY·QQQ·IWM·VIX, 적용 범위를 밝힌 소형주 신규 진입 환경, 시장맵, 산업 카드, 기존 발굴 규칙의 기업 후보와 반론.
2. **산업·테마**: 수요 → 매출·이익 연결 가설, 확인할 지표, 반대 시나리오, 구분해서 제시하는 ETF 가격 참고값. 기존 다음 사이클 업종의 재무 가속 분석도 연결한다.
3. **시장맵**: 매매 패턴 통과 여부와 무관한 가격 표본을 탐색. 테마·세부 사업·기간·시총/동일 비중·검색·목록/지도 보기. 조건을 적용한 뒤 시총 순으로 최대 240개(첫 화면 64개)를 그린다.
4. **기업 요약**: 사업 연결 가설, 관측된 가격·분기 변화, 확인되지 않은 증자·실적 일정, 관련 기사 원문. 가격 상승의 직접 원인이 확인되지 않았으면 명시한다. SEC 원문과 전체 기업 분석으로 이어진다.
5. **관심종목**: 기존 저장 구조를 재사용한다. 목록에서 가격·실적 변화와 다음 위험 확인 항목을 함께 보고 검토를 이어간다.
6. **성과·고급 도구**: 기존 원장·성과·스캐너·차트·공시·데스크·알림 도구를 보존한다. 새 화면에서 이 기능들이 새로 검증된 알파 모델인 것처럼 표현하지 않는다.

## 데이터 기준

- 기존 Alpaca 일봉 캐시와 공개 `data` 브랜치의 회사·랭킹 자료를 사용한다. 새 유료 공급자와 추가 공급자 API 호출은 없다.
- `market-map.yml`은 야간 파이프라인 성공 후 실행하며 공유 데이터 쓰기 동시성 그룹을 사용한다. 별도 실행과 분류 변경 시 갱신도 지원한다. 공개하는 파일은 `market-map.json` 하나다. 기존 원장은 수정하지 않는다.
- 가격 날짜가 스냅샷 기준일과 다른 항목은 제외한다. 누락된 등락률을 0%로 채우지 않는다.
- 추정 시총은 완전한 현재 주식 수를 보장하지 않는다. 프로필 기반 값은 관측 당시 시총과 이후 조정종가 비율로 추정하므로 이후 발행·매입과 배당 조정 등의 오차가 남는다. 해외 발행사·보고 양식 미확인 종목은 통화·ADR 비율 검증 전 시총 모드에서 제외한다. 동일 비중 모드의 가격 조회는 유지한다.
- 테마는 비포괄적인 편집 분류다. 관련 부문 매출 비중·수혜 규모·경쟁력의 검증을 뜻하지 않는다. 기업이 여러 테마에 포함될 수 있다. 전체 테마 지도에는 한 번만 배치하고 개별 테마에서는 해당 기업을 조회한다.
- 지도에 표시하는 업종 수익률은 표시 기업의 가중 평균이다. 전체 시장·공식 산업지수 수익률이 아니다. 테마 ETF도 해당 세부 사업이나 미국 기업 전체를 정확히 대표하지 않으며 카드마다 범위를 설명한다.
- 실적·증자 미확인을 안전함으로 바꾸지 않는다. 기사 목록이나 가격 움직임만으로 상승 원인을 확정하지 않는다.

## 검증과 남은 제품 과제

새 테스트는 시장 표본과 셋업 분리, 누락·과거 가격 처리, 테마 중복 편입, 가중 수익률 분모, 시총의 통화·ADR 기준, 복수 클래스, 미래 자료 배제, 캐시 재사용과 원본 파일 보존, 공유 링크를 검사한다. 브라우저에서는 1440·1024·768·390·360px 화면, 검색·필터·4개 기간, 모달 키보드 조작, 관심종목 저장/재접속/삭제, 뒤로가기, 기존 데스크 접근, API 장애 중 공개 스냅샷 유지와 잘못된 주소 복구를 확인한다. 배포 결과는 GitHub Actions와 실제 운영 사이트에서 별도로 검증한다.

아직 추천 가능한 상용 리서치 제품의 모든 요건을 충족했다고 주장하지 않는다. 다음 작업의 우선순위는 다음과 같다.

1. **재무 정규화와 주식 수**: 보고 통화·분기/누적/TTM·일회성 손익·ADR 비율·주식종류·희석 후 주식 수를 종목별로 검증하고 출처를 보관한다. 검증 전 가치 배수는 기업 화면에서 보류한다. 기존 정량 모델의 과거 점수는 이번 시총 처리로 소급 재계산하지 않았다.
2. **산업의 실물 지표**: 출하량·재고·수주·가동률·전력 계약·양산 고객 등의 시계열과 기업 부문 매출을 연결한다. 지금의 ETF 가격 국면을 실적 상승 초입이라고 오인하면 안 된다.
3. **상승 이유의 검증**: 공식 공시·실적발표·가이던스의 시간과 가격 반응을 대조하고 사실·가능한 설명·불확실성을 분리한다. 현재의 원인 미확인을 생성형 문장으로 채우지 않는다.
4. **전향 성과와 모델 검증**: 거래비용·슬리피지·상장폐지·당시 유니버스·선택 편향·다중 실험을 재검토한다. 기존 과거 수익률 요약이나 규칙 점수만으로 우위를 확정하지 않는다. 새 관찰 기준도 전향 원장에 쌓은 뒤 평가한다.
5. **사용자 검증**: 신규 사용자가 산업에서 기업의 핵심 근거·반론·다음 확인 조건까지 찾는지 실제 사용성 테스트와 기간별 재방문을 측정한다. 모바일 검증은 브라우저 에뮬레이션이며 실기기 검증은 별도다.

기존 데이터·관심종목·계정·공시 파이프라인을 보호하면서 이 과제를 순차적으로 해결하는 것이 목표다.
